# wireframevibe3d

The goals :

1) Casual mindless building of 3d objects on tablets and desktops , or may be phone (not sure yet).
2) Avoid mistakes by forcing orthographic views for some operations. 
3) Repetitive workflow rather than tools that require mental context switching. (The mindless part).
4) A single page tutorial should cover everything without scrolling. I should be able to pick the app after 3 months of no usage and see one tutorial to pick up where i left. (The Casual Part)

In progress

Fully vibe coded with some basic design and coding guidelines. 

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run dev
```
