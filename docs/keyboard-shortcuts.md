Assign Keyboard shortcuts to different functionalities.

A - Insert Button
Q - Auto Connect button

D - Move Vertex button

F - Draw Edge button
G - Face Fill button

E - Clear Selection
Shift (Hold) - Multi select button

V - Equivalent to double clicking the view to move to the closest orthographic view. if a face is selected, then pressing V will move to face orthographic view.

Esc - Switch 3d view (3D view button)
