# Vertex Functions:

The user should be able to do the following in a orthographic view:
* Place vertices. Vertices always snap to the nearest grid point. 
* Select a single or multiple vertices at the same time. Selection is freeform drawing.
* Translate selected vertices  in that view plane only. if its showing the view from X axis , and when user moves a vertice, then it should translate only in YZ plane.
* Select two vertices and join them with a line.
