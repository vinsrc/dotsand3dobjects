create a basic 3d modeling app for hard surface modeling. 

# UI Design

Refer to the ui_screen.png for placements of ui widgets.

# View Selection:

The view can be changed by using a 3d axis gizmo on the bottom left corner of the screen. like blender 3d view selection. moving the 3d view gizmo should rotate the view.
Follow blender's , view selection approach.  tapping the X,Y,Z,-X,-Y,-Z changes to the specific orthographic view.

# Orthographic View:

Any orthographic view has grid of 1 unit. It should provide Zoom in and out functionality. If its a desktop, then using mouse wheel and, if its tablet, then two finger gesture for zoom in and out is used.

# Tool bar buttons:

In the tool bar, First button : load a  Wavefront OBJ format 3d file. 
Second button : export current model as a Wavefront OBJ format 3d file. 
Third button : Toggle wireframe view or shaded view
    Wireframe view shows the wireframe of the 3d model.
    Shaded view shows a light grey material with flat shading only.
